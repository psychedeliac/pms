# PMS (Property / Project Management System)

A modern web application built with [Next.js](https://nextjs.org/) (App Router), TypeScript, and Tailwind CSS.

- **Repository**: [https://github.com/psychedeliac/pms.git](https://github.com/psychedeliac/pms.git)

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.x or later recommended)
- npm, yarn, pnpm, or bun

### Installation & Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
